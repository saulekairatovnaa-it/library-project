# Кітапхана ақпараттық жүйесі (Library Management System)

Бұл жоба — кітапхана жұмысын автоматтандыруға арналған ақпараттық жүйе жобасы. 
Жүйе оқырмандарды, кітаптар қорын және кітап алу-қайтару процестерін басқаруға мүмкіндік береді.

## Жобаның құрылымы (Project Structure):
* `docs/requirements.md` — Ақпараттық жүйеге қойылатын функционалдық және функционалдық емес талаптар.
* `docs/use-case.md` — Пайдаланушылардың жүйемен өзара әрекеттесу сценарийі (Use Case).
* `diagrams/` — Жобаның UML және BPMN диаграммалары (AS-IS және TO-BE модельдері).
